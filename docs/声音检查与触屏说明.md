# 琴阶 1.11：声音检查与触屏稳定性

## 使用方式

直接覆盖安装 `release/Qinjie-1.11.0-Android.apk`，不必先安装1.10.1。沿用 `cn.qinjie.piano` 与本地原证书，版本编号13。可以先从设置导出记录；不要卸载或清除数据。

练习页和设置页显示“读取离线采样”和逐份解码进度。数量由当前音色实际采样决定：三角钢琴11份、立式钢琴8份，不使用模拟百分比。首次准备完成后复用当前音频环境的缓存。进度只表示采样准备情况，并不保证系统扬声器实际有声。

失败时保留错误文字并显示“重试音源”。重试不会清除课程或练习记录，也不会自动开始练习、评分或替换钢琴音色。单份采样解码15秒无结果会退出等待；声音启动8秒无结果提示重试。用户切后台或切页后取消原播放请求。

设置 → 选择你的钢琴 → 声音检查：

1. 调整设备媒体音量，留意蓝牙耳机或其它音频输出。
2. 点“播放检查音”，当前音色依次播放C4、G4、C5；点“停止声音”可中途结束，也能取消尚在准备的检查。
3. 播放结束后自行选择“听到了3个音”或“没听到声音”。应用不使用麦克风，不能自动判断是否听见。后者给出音量、耳机/蓝牙和更换另一音色重试的建议。
4. 仍有问题，可展开“查看声音检查信息”，点“选择检查信息”后长按复制，或截图反馈。

检查信息仅在当前运行中生成，包含应用版本、当前音色、采样进度/错误、音频环境、最近8条准备状态以及本轮听觉确认结果。在安卓上可读取制造商、型号、安卓版本及WebView版本；无相应桥接时只显示浏览器信息。信息不含歌曲音符、练习成绩、目标、笔记或个人练习记录，不会联网发送，也不会加入练习成绩。关闭应用后本次检查和准备日志不保留。

## 加载修复与触屏行为

包含1.10.1的原生采样读取：安卓优先从自己的APK读取固定的 `grand` 或 `upright` 音源；前端解析返回的JSON数据，脚本读取保留为后备。APK完整包含两套音源，但用户反馈的Tab S10+具体失败原因尚无设备日志可确认。

进度按音频环境和音色分别保存。快速更换音色时，旧音色迟到的错误不会覆盖已选音色的就绪状态；失败重试会重新解码，旧的超时回调不继续准备。

采样就绪且音频正在运行时，按键直接创建实录采样声音。冷加载过程中，松开再按同一位置时，用按键标记区分每一次按下，只允许尚未松开的最新一次发声；不会在加载结束后补播已经松开的旧触碰。滑出琴键、多指松开和触控取消都释放对应声音。失去窗口焦点会停止示范，将当前普通练习收为部分练习并释放按键，返回后由用户重新开始。

音色、包络、220毫秒释放与输出限幅算法沿用上一版。正式考核判分和课程/曲目编号保持一致。

## 验证范围

- 78项Node检查通过，包括进度真实计数、超时后重试、迟到回调、上下文状态隔离、原课程/曲库/识谱/考核/复习算法。
- Chrome交互检查覆盖原生音源桥接模拟、全部动态采样请求被阻断仍播放、准备进度、听觉确认、停止与取消、冷加载期间快速重复按键、滑动、多指释放、失焦收卷、旧音色失败隔离，以及横竖屏布局。
- 两种音色、练习选段、回放、跟练、错点复习、教学资源、实时切谱和iPad共享界面回归通过。
- OfflineAudioContext实际波形检查两套采样的起音、松手连续性、归零尾音、取消未来声音及16音峰值；结果位于 `release/previews/audio-check-1.11.0.json`。
- APK资源、签名和哈希核对见 `release/1.11-更新说明.md`。

安卓Java编译通过，原生桥接在浏览器测试中使用模拟。没有Android模拟器、Samsung Tab S10+或iPad真机验证；浏览器通过不能当作真实平板问题已解决。用户在本次开发前尚未安装1.10.1。iPad仅同步源码，签名和云端编译仍暂停。
