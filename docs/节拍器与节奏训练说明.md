# 琴阶1.12：节拍器与节奏工坊

## 怎样开始

安装 `release/Qinjie-1.12.0-Android.apk`，直接覆盖更新。侧栏“节奏”、首页“节拍与节奏工坊”和成长页均可进入。

先在60 BPM练“四拍走稳”，再练“拍一下，等一下”。每种节奏有4个完整小节，先听一遍，再触碰大拍击区。●表示在格子起点拍一下，格子宽度表示后续等待时长；0表示休止。下方数字是本小节拍点位置，不是钢琴指法或音高简谱。

开始后先听一小节预备拍，训练目录和设置收起，拍点与拍击区集中展示。可按住后松开，但按住不会重复计数；这里只检查每次触碰的起点。也可在电脑聚焦拍击区后用空格或Enter练习。

## 独立节拍器

- 35—160 BPM，2/4、3/4、4/4拍。
- 整拍、半拍或四分之一拍细分，可突出每小节第一拍。
- 可关闭节拍器声音，只看拍点。
- 使用音频时钟安排点击声，提前120毫秒调度；不依赖钢琴采样读取或解码，也不需要网络、实体琴和麦克风。
- 独立运行和试听都不生成练习成绩，不折算成钢琴弹奏时间。
- 切页、切后台、失焦或停止都会结束调度，并取消尚未播放的声音。

“节拍器声音”只控制独立节拍器；拍击训练的伴拍由“练习时保留伴拍”控制。试听先播放一小节预备拍，之后只播放目标节奏。拍击练习也先播放预备拍，关闭伴拍后正文按固定时间轴独立完成。

## 9种训练

| 阶段 | 训练 | 学习重点 |
| --- | --- | --- |
| 入门 | 四拍走稳 | 4/4整拍与第一拍重音 |
| 入门 | 三拍摇摆 | 3/4强弱弱 |
| 入门 | 两拍交替 | 2/4拍点 |
| 入门 | 拍一下，等一下 | 交替的整拍与休止 |
| 基础 | 一拍分两半 | 均匀八分节奏 |
| 基础 | 长短接起来 | 半拍与整拍衔接 |
| 挑战 | 附点不抢拍 | 一拍半后接半拍 |
| 挑战 | 从后半拍进入 | 半拍休止与后半拍进入 |
| 挑战 | 四等分小挑战 | 十六分、整拍、半拍与休止组合 |

这些是原创的拍击节奏，不加入原曲库，不改变内置歌曲或课程ID。用于练习拍点和等待，不是完整歌曲、钢琴时值评价或正式考级项目。

## 反馈与匹配规则

本轮使用固定音频时钟，不因用户整体提前或滞后而移动目标。使用事件时间戳换算拍击时间，当前有效设备校准可从考核页读取；导入备份仍清除设备校准，不自动套用其它设备的修正。更换输出设备后应重新校准。

每个目标最多接受一次拍击。按时间顺序记录，重复拍击会成为额外输入；不会把后一次更准确的重复拍替换第一次。目标窗口根据速度与相邻目标间隔限制，彼此不重叠。

设每拍时长为u秒，前后目标间距为d₁和d₂，匹配窗口为 `min(250ms, 0.45u, 0.49d₁, 0.49d₂)`；没有相邻目标时忽略对应限制。时机达标范围为 `min(80ms, 0.12u, 0.65×匹配窗口)`。首次落入窗口的拍击匹配该目标；窗口内但超过时机范围的输入分别标为偏早或偏晚。

预备拍的大部分输入忽略；接近首个目标、已经落入首个匹配窗口的提前拍击会记录，以评价偏早并支持负向设备校准。校准最多±150毫秒，沿用考核页原有校准有效性要求。没有校准时，报告明确标为参考结果，不能据此确认平板本身的音频延迟。

完整报告分别显示：

- 目标命中率：匹配目标数÷全部目标数。
- 按拍准确率：匹配数÷实际拍击数，额外输入会降低准确率。
- 命中拍的时机：时机达标数÷已命中数，不替代漏拍和多拍指标；无命中时显示“—”。
- 漏拍、多拍、偏早、偏晚、休止时多拍及平均绝对时间偏差。
- 每个拍点的小节、位置和早晚毫秒，以及额外拍击位置。

停止、离开、切后台或调度中断时，只保存已有拍击的部分练习，不对完整片段评分。没有实际拍击的中途退出不制造练习记录；用户完整走完但没有拍击时会得到完整的0命中结果。每轮最多160次输入，超过则中断并保留部分记录。

帧/音频时钟中断超过350毫秒、或需调度的声音落后时钟超过40毫秒时停止本轮。应用不会把多次逾期点击声挤在同一时刻播放，也不会把播放中断后的结果认定为正常完整训练。

## 记录与重练

保留最近30轮，成长页单独统计，可随原学习记录备份。保存原拍击时间，导入清洗时验证已知训练ID、真实日期、速度、输入范围和完成条件，报告从输入重新计算，不相信外部填入的成绩。

完整训练只与更早、同节奏、同速度、同伴拍、同细分、同重音和同校准修正的完整训练比较。关闭伴拍后，细分与重音归一为无伴拍条件；不同条件、部分练习或校准变化不混比。

“准备重练”恢复该轮速度和伴拍设置，不自动播放；实际使用当前设备可用的校准。若校准不同，界面说明变化，新报告不会沿用旧修正。
