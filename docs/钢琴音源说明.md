# 琴阶 1.6 钢琴音源

1.6将按键发声从正弦波叠加改成钢琴实录采样。内置两套独立音源，首次打开练习页或设置页会提前准备所选音色，随后按键直接播放已解码采样。音色选择随练习记录保存和备份，所有课程试听、曲目示范、自由弹奏、识谱训练与回放共用该选择。

## 实录来源与许可

- **三角钢琴 / Salamander Grand Piano**：Alexander Holm录制的Yamaha C5。音频来自[Tonejs/audio的Salamander目录](https://github.com/Tonejs/audio/tree/master/salamander)，原始项目说明和许可随包放在`samples/Salamander-README.txt`。许可为[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。选用11个采样根音，54、57……84，相邻音最多移调1个半音。
- **立式钢琴 / VSCO 2 CE**：Simon Dalzell（Ivy Audio）录制，由Versilian Studios发布。使用[官方仓库](https://github.com/sgossner/VSCO-2-CE/tree/master/Keys/Upright%20Piano)的dyn2层、rr1样本，8个根音57、61……85，相邻音最多移调2个半音。许可为[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)，原始LICENSE和Info.txt随包保留。官方[项目页](https://versilian-studios.com/vsco-community/)也明确允许再分发。

上述品牌仅用于标明录音乐器来源，无官方合作或背书。立式钢琴不虚构厂牌。

## 琴阶的处理与限制

采样去除敲击前多余空白，保留约3ms起音前沿；最长截取12秒，末尾250ms渐隐。每套乐器统一增益，保留琴键间的相对音量；转为44.1kHz、192kbps立体声MP3。原始下载及处理后数据的SHA256、来源固定提交和裁剪位置记录于`samples/manifest.json`。

MP3以Base64封装到两个独立JS音色包，按需加载；这样Android离线HTTPS资源与iPad本地file资源都可使用，运行时不下载网络音频，也不放宽iPad的connect-src 'none'。解码后播放AudioBuffer，19个根音覆盖应用G3–B5音域；不循环拼接尾音、不重新合成谐波。两套音色共约7MB脚本，APK压缩后更小；解码缓存会占用额外内存。

触屏为固定力度，没有模拟真正的轻重触键或完整16层力度；这不是完整SFZ采样器。没有实现独立踏板共鸣或琴槌松键噪声层。琴音会自然衰减，松键再用220ms指数收音与5ms归零消除截断，和弦经过压缩及末级软限幅以控制削波。设备扬声器仍会影响低音和空间感。

## 再生成与检查

运行`scripts/prepare-piano-samples.py`（需numpy和imageio-ffmpeg；脚本优先使用`.build/pydeps`），只下载清单中的公开录音；原始文件缓存位于`.build/piano-source`，不加入源码交付包。测试：`node --test tests/audio.test.cjs`、`node tests/audio-ui.cjs`、`node tests/timbre-ui.cjs`，后两者需要本地预览服务和Playwright/Chrome。

波形测试应包含起音中松键、持续音中松键、旧WebView兼容路径、计划释放中再次松键、未来音取消，以及多音和弦。浏览器可验证解码、波形和操作流程，不能替代真实安卓平板或WKWebView的音质、延迟、后台和资源压力检查。
