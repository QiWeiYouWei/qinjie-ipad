# 琴阶1.10：逐小节复盘与错点复习

安卓离线触屏版1.10.0，2026-10-13。原28节课程、39项内置曲库、专题、小测、采样声音、正式考核与训练处方保留。

## 从一遍练习到下一遍

在曲库选择一首，开始普通“找音”或“节奏”练习。结束后原有整体命中率、按键准确率和起音达标率保留，新增“逐小节复盘”。优先列出有错点的小节；无错点时显示已分析的小节。

每小节列出目标音命中、漏音和额外／错按。节奏模式还分别列出偏早、偏晚及休止时起音。小节号按原曲定位，即使只练第3—4小节，仍显示原第3、4小节。

点击标有目标BPM的“练这里”按钮选中该小节，速度降低10，最低35 BPM；“连前后小节练”包含前一小节、本小节与后一小节，不越过曲头或曲尾。这两个按钮只准备练习条件，点“开始练习”才开始弹。模式、提示、谱式和钢琴音色沿用报告，关闭自动循环。

“按本次条件再弹一遍”沿用原小节范围和速度，中途退出也保留原请求范围。中途结束时上方整体结果标作全片段进度与尚未命中，下方只评价已练到部分。同一原曲与谱面、范围、模式、速度、提示、谱式和音色的完整片段，才与更早完成的一遍比较命中率、额外／错按及起音达标率。降低速度后先建立新基准，不把不同条件混为进步。普通练习没有设备延迟校准，跨设备比较仅供参考。

“前半段／后半段”现按小节分割，不再按音符组数量截断；小节数为奇数时，前半多一个小节，两段不重叠。仅有一个小节时，两项都指向该小节。跟练的后半段起点同步采用这个边界。

## 统计规则与限制

- 找音模式会等你找对再前进，因此通过的组没有漏音；曾经错按、后来改对仍留下额外／错按记录。它不评起音节奏。
- 找音中途结束只分析已经完成的音组；尚未完成的当前组和后续组不判漏音。
- 节奏模式沿用普通练习的实际匹配结果，起音偏离目标超过0.18拍时分别计早或晚，匹配窗口仍为前后0.5拍。错音、重复或窗口外起音归入额外／错按。
- 节奏中途结束只分析已经过完起音匹配窗口的目标；尚在窗口内或未到的目标不判漏音。
- 双音中的每个目标音分别计数。同一次起音只消耗一个实际匹配，不将重复按键用于多个目标。
- “休止时起音”表示在休止时新按键。这里不检测持续按住前音穿过休止，也不评松键时长；这些仍在专项／正式考核里评价。
- 超过普通回放的实际起音记录上限（5分钟或600次输入）时不生成新的精确逐小节报告；原整体结果保留。

“片段已走完”表示普通练习的结束条件，不代表实体钢琴技能达标；找音模式最后按下即可走完，不据此评末音保持。此功能不添加新的专业综合分，不替代正式考核的音符时值、连贯、双音整齐或休止保持评价。

## 集中复习、曲谱更新与备份

成长页打开“错点复习”，保留最近30份实际普通练习的逐小节报告。每份可同条件再练，或直接慢练前三个错点小节；展开明细查看全部小节。

报告通过稳定歌曲ID关联，并保存当时完整音符、时值与拍号用于核对。曲目移除、同ID更新了音符、时值或拍号时，旧报告继续显示，但禁用原小节练习入口，提示重新练当前谱面生成新报告。若只更新文字说明、音符、时值与拍号不变，定位仍可用。不会因曲库索引移动而串到别的歌。

逐小节报告随学习记录备份和恢复。旧版本只有整体分，没有足够的实际逐小节数据，因此不推算或伪造旧报告；旧课程、学习笔记与考核记录照常保留。

## 检查范围

新纯逻辑检查覆盖找音纠错、节奏早晚漏音、同键额外起音、休止中后段、部分练习、小节原位置、速度边界、同条件比较、更新保护、备份与无效记录清洗。浏览器使用实际触屏输入及Web Audio时钟检查报告、慢练／衔接、重练比较、回放期间禁用操作、更新后的入口保护、记录恢复和横竖屏布局。

原采样音源与释放包络未改动。本轮浏览器播放检查不是新的实际波形测量，也不等于真实安卓平板或原生iPad检查；真机触控、扬声器输出和系统文件选择器仍待验证。iPad仅同步工程，签名与云端编译继续暂停。
