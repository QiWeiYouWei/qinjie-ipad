# 琴阶1.8：训练处方、分项工坊与趋势

## 从报告到练习

导航点“考核”，先选择学习阶段和简谱/五线谱/对照。训练处方查找最近一次**同阶段、同谱式、完整结束且有总分**的考核；未校准考核也可作为建议来源，但会注明节奏建议仅供参考。中断不生成处方依据。没有对应记录时提供起音、时值、视奏的入门建议。

处方对三段演奏的适用维度取算术平均；不把不存在的双音、休止记作弱项。听辨和乐理使用各自分数。建议线：音高85、起音80、时值80、连贯80、双音85、休止90、听辨80、乐理80。按“得分/建议线”从低到高列最多三项；全部达到建议线后推荐新谱视奏。建议线用于安排训练，不替代1.7正式考核的评分门槛。

每项建议约2分钟：慢练一遍、看具体偏差、保持速度再减掉提示或节拍器。应用不宣称两分钟即可掌握技能。首页有训练处方入口。

## 11种分项训练

六类技能：找音与跳进、起音节奏、长短音保持、连续音阶、双音起落、休止与收音。另可单独训练原考核的基本技术、完整短曲、随机视奏、听辨、乐理。

技能谱共24份（6类×A—D），都是原创四小节、16拍，末句回到中央C，非官方考级规定曲目或专业钢琴原谱。部分阶段沿用相同基础谱，在不同规定/自选速度下训练；双音项目实际曲库难度至少为“提升”，入门学生可自由尝试但不把它标为简单单声部。音域C4—C5，每组最多两个音。

生成源为`scripts/build-drill-repertoire.cjs`，稳定ID为`qinjie.drill.技能.阶段编号`。可导入`release/曲库模板/训练处方.qinjie.json`到普通曲库，使用原有试听、选段、回放。原39项内置曲目和8项考核谱的编号、旋律均不变，导入协议仍为`qinjie-song-pack/1`。这些短谱是完整专项练习，不是新增24首流行歌曲。

训练速度35—120 BPM，可开/关全程节拍器和琴键/谱面提示。速度与辅助设置会保存，正式五部分考核仍用固定速度，辅助关闭。随机视奏仍有30秒准备，并每次生成新谱。听辨最多听两次，播放完才能选；听辨和乐理仅收第一次答案，随后讲解，点“下一题”才继续。正式考核仍统一收卷后反馈。

演奏训练沿用真实按下/松开、一对一匹配和六维判分。演奏训练达标要求原本站门槛，且对应专项维度至少80；听辨、乐理需至少80分，即5题中4题首次答对。训练全部是**训练参考分**，即使训练达标也不认定完成正式五部分考核。节拍器开启还会帮助节奏，因此不把有辅助的分数当作无辅助能力。

报告保存速度、提示、节拍器、阶段、谱式和当前校准修正。可点“同条件再练一遍”，沿用速度、辅助、阶段和谱式，重新出题并使用当前设备校准；设备校准变化后不与旧修正的成绩直接比较。切后台、离开、触控取消或计时中断记录为未完成，不出分数。

## 两种比较

**正式趋势**仅显示同阶段、同谱式、已校准、完整完成的最近8次考核。显示最高分与较上次变化，图中每次成绩都有日期列表。不纳入训练、未校准参考分、中断或其他阶段/谱式。随机题及当天状态仍会影响成绩，曲线是自测记录，不证明专业技能评级。

**训练对比**在报告中寻找当前记录之前、同项目、同阶段、同谱式、同BPM、同节拍器/提示开关、同校准修正的最近完成记录。不取未来记录，不拿不同速度或辅助设置进行增减比较。中断只说明未完成，不显示“null分”或趋势变化。

## 记录与验证

本机保留最近50次专项训练，与最近20次正式考核独立。成长页显示训练完成和训练达标数量，不折算成普通练习时间。完整备份包含训练设置、独立历史、分项分数、答题与按键明细；旧备份缺少该模块时正常升级为空记录。每段保存最多160条按键明细和80条偏差，全部输入先参与判分，统计不会因明细截断而改变。

`tests/coach.test.cjs`验证谱面完整性、35/60/120 BPM理想输入、处方来源与排序、趋势筛选、独立记录清洗、同条件比较和解释覆盖。`tests/coach-ui.cjs`用真实Web Audio时钟和Chrome原生触屏事件完整跑两次80 BPM时值专项，检查节拍器、保持评分、复练比较、答后讲解、听辨锁定、中断、备份、成长、三种平板布局与24首包导入/记谱。`tests/exam-ui.cjs`回归原五部分考核。

这些是浏览器与源码检查，尚未验证真实安卓平板/iPad的触控、音频延迟和系统后台行为。1.8没有改动实录采样音源与释放包络，沿用1.6已验证的波形；iPad仅同步本地工程，不恢复签名或云端编译。
