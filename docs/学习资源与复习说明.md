# 琴阶1.9：学习资源与知识复习

适用于安卓离线触屏版1.9.0，2026-10-13。iPad仅同步本地开发工程，签名与云端编译继续暂停。

## 怎样开始

首页打开“学习资源与每日复习”，或导航点“乐理”。保留原28节课程、15张声音知识卡和39项内置练习。新增专题不会改动旧课程或曲目编号。

新资源有12个专题：拍点细分、休止与收音、附点、弱起、长音与重复、半音、音程、大小三和弦、调性中心、乐句、指法、慢练与复习。支持按分类或关键词查找。每页包括学习目标、三段讲解、完整四小节原创例谱、实录钢琴试听、三步练法、常见误区和两道带解释的小测。

例谱显示简谱、五线谱或上下对照，音高与时值一致。以1=C为参考；A小调专题仍使用这套固定音高显示，并以A收尾。变化音以升号等音显示。三和弦专题使用分解音型，原声音知识卡可以试听同时发声的完整三和弦。弱起专题以三拍休止填充开头，在第4拍进入，是完整四小节教学例子。

每页“导入例谱去练习”先显示歌曲包预览，确认后进入我的曲库。可以选段、降低速度、跟练、录制回放；同ID再次导入会更新原例谱。全部12份也可一次导入`release/曲库模板/知识专题例谱.qinjie.json`，继续使用`qinjie-song-pack/1`协议。

## 每日复习怎样安排

原课程的两道检查题和新专题的两道题共80题。只有加入安排的题目进入待复习，不要求一次学习全部资源。

- 原课程答对两道检查并标记“已学习”后，两题安排次日复习；原阅读检查仍允许重试，保持旧行为。
- 旧版已完成课程升级后，缺失的两题加入当日待复习，不伪造以往答题或理解成绩。
- 专题小测首次作答会加入安排；也可以点“加入复习计划”，将尚未答过的两题加入当日待复习。
- 每题每天只记录第一次选择，随后显示正确答案与原因；当天再点不能刷成绩。
- 答对后的间隔依次为1、3、7、14、30天，后续保持30天。答错重置为次日再测。
- 每轮最多10道已到期题，按到期日优先，同日优先错得多的题。日期按设备本地日历，间隔以日计算，跨月和闰年正确处理。
- 每次作答即保存。退出本轮保留已答题，未答题继续待复习，未答不计错；可以稍后继续。

成长页单独显示最近200道首次作答、答对数和今日待复习数。知识复习不计入练琴分钟，也不混入正式考核、专项演奏或识谱训练成绩。这是透明的固定间隔复习机制，没有经过学习效果临床或教学实验验证。

## 收藏、笔记与阅读

原课程和新增专题均可收藏。每页笔记最多1200字，输入即保存到本机；保存失败会明确提示，不显示“已保存”。资源页“我的收藏与笔记”集中显示两类页面，支持返回原讲解。

阅读可选择标准字号或大字，偏好同时用于课程与专题。首页和资源页提供上次打开的课程／专题入口。记录最后打开的页面，不记录页面滚动位置。

导出学习记录会包含笔记、收藏、字体偏好、最近阅读与复习安排。导入旧备份时兼容缺失的字段，已完成课程按上述规则补复习题；原导入仍需要确认替换记录。曲库备份与正式考核设备校准规则沿用原流程。

## 内容与检查边界

例谱是原创教学简编，完整16拍与结尾，用于示范单一概念，并非完整流行歌曲、专业原谱或官方考级规定曲目。指法、力度、踏板和实体琴动作只提供讲解；触屏无法自动判定使用了哪根手指，也无法认定实体钢琴技能等级。

交付前用实际校验器验证歌曲包，同时核对每小节拍数、结尾、弱起位置、附点长短、休止、分解和弦与C大调音阶。JSON结构校验不能独自证明旋律准确。

本版使用原采样音源与释放包络，没有修改音频算法。Chrome检查使用真实Web Audio解码和播放，验证试听、停止及准备期间退出取消；并检查离线file页面、备份恢复与平板尺寸。以上不等于真实安卓平板或原生iPad验证；设备扬声器、触屏延迟与原生系统文件选择器仍需真机检查。
