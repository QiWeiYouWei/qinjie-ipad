# 琴阶 1.10.1 音源加载修复

用户反馈：Samsung Tab S10+ 覆盖更新 1.10.0 后，课程练习提示“音源加载失败，请重新安装完整版本”。未取得设备日志，具体触发原因尚未确认。

## 修复

- 确认旧 APK 包含两套完整采样，旧提示不能作为文件缺失的证据。
- 安卓新增仅允许 grand / upright 的原生读取通道，直接读取 APK 内采样，向前端返回 JSON 数据，不执行桥接返回的代码；单文件上限 5 MB。
- 优先使用原生通道，共享网页脚本加载作为后备。保留离线网络限制、两种实录音色、原包名和原证书。
- 脚本加载失败/超时可重试，清理旧回调；错误持续显示在音源状态，练习开始失败也显示原因。去掉无依据的重新安装提示。
- 无课程、曲目 ID 或本地记录结构变更。

## 安装

1. 有条件可先在设置导出练习记录。
2. 下载 Qinjie-1.10.1-Android.apk，直接点更新；不要卸载或清除应用数据。
3. 打开设置 → 选择你的钢琴，先点试听，随后切换另一音色试听，再进入课程练习。
4. 如仍失败，请保留记录，并提供设置页完整错误截图及安卓版本。
