# 琴阶1.12.1：离线音源读取修复

用户提供的1.12.0立式钢琴日志确认读取失败而未进入解码，设备为Samsung SM-X820 / Android16 / WebView153。

## 根因与修复

旧APK音源实际条目为 assets/samples\grand.js 和 assets/samples\upright.js，原生和脚本都按标准斜杠路径查找，因而失败。Java精确查找旧包条目返回null；此前Windows Python .filename自动规范化路径而漏检。

新构建流程在对齐/签名前规范化6个音源子目录条目，最终条目为 assets/samples/grand.js、assets/samples/upright.js。检查改为原始orig_filename与Java读取/哈希验证。

补充16KB原生分块读取、取消安卓端对大音源对象的JSON重解析、双通道错误诊断、原生版本号和关闭资源缓存；分块不是已证实的根因，归档路径错误已直接复现。完整工程说明见[音源路径修复](../docs/安卓音源路径修复说明.md)。

## 安装

只安装 Qinjie-1.12.1-Android.apk，直接覆盖更新，保留课程、记录和导入曲库，无需其它APK或中间版本，不要卸载或清除数据。打开设置，选择立式钢琴试听，再试三角钢琴；正常时显示“实录采样已就绪”。
