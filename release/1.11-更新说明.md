# 琴阶 1.11.0 更新说明

本版侧重音源加载可见性、失败恢复和触屏稳定性，包含1.10.1的安卓原生采样读取修复。用户反馈设备为Samsung Tab S10+，本次开发前尚未安装1.10.1，尚无真机恢复确认。

## 功能

- 练习页和设置页显示离线采样读取、实际解码份数；三角钢琴11份、立式钢琴8份。失败保持原因并提供重试。
- 设置新增声音检查：当前钢琴依次播放C4/G4/C5，用户确认是否听到3个音；播放或准备阶段可以停止。没听到时给出媒体音量、耳机/蓝牙输出和另一音色重试建议。无需麦克风，不自动认定设备有声。
- 可选择复制声音检查信息：应用/安卓/WebView版本、型号、当前音色、采样进度、错误和最近8条准备日志；不包含练习记录或笔记，不联网发送，本轮检查不计学习成绩。
- 单份解码15秒无响应、声音启动8秒无响应可退出等待重试；按音色和音频环境隔离状态，旧错误不会覆盖新音色。
- 就绪后的触屏直接起音；冷加载中快速松开再按只允许尚未释放的最新一次发声。多指、滑动和取消释放经过检查；失焦停止示范、保存部分练习。
- 28节课程、12个专题、39个内置曲目及稳定ID、原记录结构和考核判分算法保持一致。

## 安装

直接安装 Qinjie-1.11.0-Android.apk 并选择更新，无需先安装1.10.1。不要卸载或清除数据；可先在设置导出记录。打开设置 → 选择你的钢琴 → 播放检查音，再进入课程练习。
